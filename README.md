# KoeStudio

A Windows drawing and painting program, built to grow into a full-purpose tool in the spirit of Clip Studio Paint.

## Running it

Double-click **KoeStudio** on the Desktop or in the Start menu. It runs straight from this folder (needs Python 3.10+ and `pip install -r requirements.txt`), so there is nothing to install or build. `Run KoeStudio.lnk` and `KoeStudio.exe` in this folder do the same.

If you move the folder, recreate the shortcuts with `powershell -ExecutionPolicy Bypass -File tools\make_shortcut.ps1`.

Press **F5** or **Ctrl+R** to reload the screen (your work is saved first). The window opens where and as big as you last left it (maximized too); if that screen is gone, it opens centred.

## Where your work goes

- Artwork saves automatically to **Pictures\KoeStudio** as `.koe` files. If a save fails (disk full, file busy), KoeStudio says so and keeps retrying.
- **Earlier versions:** while you work, a copy is kept every 10 minutes (the newest five per artwork, in `.backups`). Open one from the card's **⋯** menu in the gallery or File → Earlier versions…; it opens as a copy, so the artwork itself is never changed.
- **Deleted artwork** goes to the `.deleted` subfolder; put it back with **Deleted** at the top of the gallery.
- The **⋯** menu on each gallery card also renames and duplicates artwork.
- **Exports** go to **Pictures\KoeStudio\Exports** unless you pick another folder. **File → Export…** (Ctrl+Alt+Shift+S) chooses PNG, JPEG, WebP, GIF, TGA or BMP, the size (in percent; whole-number enlargements stay pixel-sharp), the JPEG/WebP quality, with or without the paper colour, only the selected area, and where it goes: **Browse…** opens a file browser with Exports, Desktop, Pictures, Documents, Downloads and your drives, a New folder button, and the files already there (click one to reuse its name; you are asked before a file is replaced). Your choices and the folder are remembered, and Ctrl+Shift+S exports a PNG straight into that folder (numbered, never replacing). File → Save project file (.koe)… writes the whole layered artwork wherever you pick in the same browser; open it again from the gallery with **Open image or project…**, or double-click the file in Explorer (run `tools\register_koe.ps1` once to set that up; it uses the bundled `KoeStudio.exe` launcher, which needs Python installed).
- Tool settings and colours are kept in `%LOCALAPPDATA%\KoeStudio`; saved brushes and their tip and texture images in its `brushes` folder.

## Features

- **Help menu:** **Guide** (F1, also a button in the gallery) explains every part of KoeStudio on short pages, with a search box; **Keyboard shortcuts** lists every key; **About KoeStudio** shows the version and where your artwork and settings are kept.
- **Gallery** of your artwork with thumbnails; new canvas presets (Full HD, A4 and B5 at print resolution, square, icon) or any size up to 10,000 px, with a resolution (dpi) that shows the print size; open any image as a new artwork.
- **Tools:** Pen, Pencil, Brush, Airbrush, Eraser, Smudge, Liquify, Blur, Dodge, Burn, Clone stamp, Fill, Gradient, Lasso fill, Figure, Text, Rectangle and Ellipse selection, Lasso, Polygon, Magic wand, Crop, Eyedropper, Move, Ruler, Hand. The **Tool property** panel next to the tool bar shows the current tool's settings; click its heading to fold it away. For the pen tools it keeps the basics (size, opacity, density, hardness, stabilization) and **Brush settings…** opens a floating window with every setting on pages (Paint, Tip, Pen pressure, Stroke, Variation, Texture), as Clip Studio Paint's Sub Tool Detail. You can paint with it open; drag it by its title bar. A preview stroke at its top shows every change at once. It remembers whether it was open, where, and the page.
  - Pen pressure for size and density, with a pressure curve and a minimum size and density. **File → Pen pressure settings…** sets one pressure curve for every tool (Soft, Normal, Firm, your own, or fitted to a few test strokes on its pad).
  - Stabilization (smooths shaky lines), hardness, density, spacing. Each tool remembers its own settings.
  - **Brush textures:** paper, watercolor paper, canvas, chalk and noise grain, or your own texture image, with strength, size and invert. The grain is fixed to the canvas, so overlapping strokes share it like real paper. The Pencil has a paper grain by default.
  - **Brush tips:** round, or any picture as the tip (Brush ⋯ → Add tip image…; a picture with transparency uses its shape, an opaque one uses its dark parts). Squash, angle, random turn and turning with the stroke work for every tip.
  - **Tilt and speed:** tilting the pen can make the brush bigger (up to three times when it lies flat) or lighter, or turn its tip the way the pen leans; fast strokes can get thinner or thicker, lighter or stronger (Brush settings → Tilt and speed). Not on vector layers.
  - **Variation:** Scatter throws each dab off the stroke by up to a multiple of the brush size, Size jitter and Density jitter make dabs randomly smaller or lighter, Hue, Saturation and Brightness jitter vary the colour of each dab (or once per stroke), and Start taper (under Stroke) starts each stroke thin and grows it to full size over that many pixels. End taper thins the end of each stroke the same way; since the end is only known when you lift the pen, that last stretch appears then.
  - **Saved brushes:** the Brush row at the top of the pen tools' settings loads a saved brush; its ⋯ menu saves the current settings as a new brush, updates, renames or deletes one, and manages tip and texture images.
  - **Importing brushes:** Brush ⋯ → Import brushes (Procreate, Photoshop, GIMP, Krita)… reads Procreate `.brush` / `.brushset`, Photoshop `.abr`, GIMP `.gbr` / `.gih` / `.vbr` and Krita `.kpp` / `.bundle` files, tip and texture pictures included, and shows every brush in the file so you can pick which to keep; each becomes a saved brush. Size, opacity, spacing, tip angle, squash and rotation, pen pressure and texture strength carry over; the dialog lists what does not (for example dual brushes, color dynamics, wet edges). Procreate does not document its settings, so those are approximate: check the size after importing. Check a brush's terms of use before using it outside the program it was made for.
  - Fill can look at all layers or only the current one, with a colour margin and an expand option that tucks the fill under line edges. Untick **Connected only** to fill every pixel of that colour in the picture. **Close gaps** keeps the fill from leaking out through small openings in line art (openings up to about twice that many pixels). **Look at → Reference layers** finds the area from the layers ticked **Reference** in the Layers panel only (e.g. your line art), whichever layer you fill on (the Magic wand has the same options).
  - The pen's eraser end erases.
  - **Smudge (J):** drags paint along like a wet finger, with size, strength and softness; pen pressure can control both.
  - **Liquify (J again):** bends the picture under the brush: Push drags it with the pen, Pinch pulls it in, Bloat swells it, Twirl turns it right or left (these keep working while you hold the pen still). Stays inside the selection and follows the symmetry ruler.
  - **Retouching:** **Blur** (J, press until it shows) softens what you paint over; **Dodge** and **Burn** (O, press again to switch) lighten and darken; **Clone stamp** (S) copies from where you Ctrl+clicked (a crosshair shows it), from this layer or everything visible, with **Aligned** keeping the same distance stroke after stroke. They stay inside the selection; Blur, Dodge and Burn follow the symmetry ruler.
  - **Lasso fill (G, press until it shows):** draw round an area and it fills with the main colour.
  - **Shift+click** draws a straight line from where the last stroke on the layer ended.
- **Figure (U, press again for the Ruler):** drag to draw a straight line, rectangle, ellipse, regular polygon or star (with the number of corners and the star's depth) with the brush size, opacity and hardness, outlined or filled; Shift makes a 45° line, a square or a circle. **Round corners** gives rectangles rounded corners of that radius. **Polyline** and **Polygon** are clicked corner by corner (Shift keeps each side to 45° steps): double-click or Enter finishes, a click on the first corner closes a polygon, Backspace takes back the last corner and Esc drops the shape.
- **Gradient (G, press again to switch between Fill and Gradient):** drag to set the direction (Shift snaps the angle). Colors main → sub, main → transparent (or the other way round), straight or circular, with opacity. **Repeat** starts the gradient over and over past its end, **Mirror** makes it go back and forth (stripes and rings). Ready-made gradients (main → sub → main, rainbow, sunset, sky, fire, night, black → white) and **Dither** against banding; a strip in the tool panel shows the colours. **Edit gradient…** makes your own gradients: add, move and colour the stops (a fixed colour, or the main or sub colour), set their opacity, and save them; they appear in the Colors list and in Filter → Gradient map. It fills the selection if there is one, and works on masks too.
- **Text (T):** click to type a new text, click a text to edit it again; click elsewhere, switch tools or press Esc to finish. Font (including Japanese fonts), size, bold, italic, alignment, line spacing and **vertical writing** (top to bottom, columns right to left, as in manga). Text stays editable on its own text layer; the Move tool moves it. To paint on it, rasterize it (Layer → Rasterize text, or the button that appears when you try).
- **Selections:** rectangle, ellipse (M again), lasso, polygon (L again: click the corners, double-click or Enter closes) and magic wand; Shift adds, Alt subtracts, Shift+Alt keeps the overlap. Select all, deselect, invert, select layer pixels; **Color range…** selects every pixel close to a colour (the main colour, or click the canvas while the dialog is open), softly at the edge of the Fuzziness, from the visible picture or the current layer; **expand, shrink, feather and border** the selection by a number of pixels (Select menu; Border selects a band along the edge, e.g. to outline a shape). Painting, fills, filters, Delete and Alt+Del stay inside the selection, softly where it is feathered. **Quick mask** (Q, or Select → Quick mask) shows the selection in red and lets every tool paint it: painting selects, erasing deselects, lower opacity selects partly, Fill and filters work too (blur it for a soft edge). Press Q again and the red area becomes the selection.
- **Transform (Ctrl+T):** scale with the handles (Shift or "Keep aspect" for proportions), rotate by dragging outside the box (Shift snaps to 15°), move by dragging inside or with the arrow keys, flip and turn 90°. **Distort** drags each corner on its own; **Mesh** puts a 4 × 4 grid of points over it, and dragging a point bends the picture smoothly around it. Enter applies, Esc cancels. Works on the selection, or the whole layer when nothing is selected. The Move tool moves just the selected pixels when there is a selection.
- **Resolution:** each artwork has a dpi (set in New canvas and Image → Image size), which decides its print size without changing any pixels; exported PNG, JPEG and BMP files carry it, so other programs print them at that size. The size at the bottom right shows the print size on hover.
- **Canvas and image size (Image menu):** Canvas size adds or removes space around the picture, kept at any of nine anchor points; Image size stretches or shrinks everything (by pixels or percent, smooth or hard-pixel). Rotate the canvas 90° or 180° and flip it.
- **Crop:** the Crop tool (C) shows a box you drag by its edges and corners (Shift keeps proportions) or redraw; Enter crops. Image → Crop to selection crops to the selection in one step, and **Image → Trim to content** crops away the empty space around everything you have drawn.
- **Copy, cut and paste:** Ctrl+C / Ctrl+X / Ctrl+V paste onto a new layer in the same spot; images copied in other programs paste too.
- **Layers:** **Lock** a layer or folder against any change, mark **Reference** layers for Fill and the wand; add, duplicate, delete, merge down, merge visible to a new layer (Ctrl+Shift+Alt+E; the layers stay as they are), rename (double-click), hide, opacity, 16 blending modes, lock transparent pixels, clip to the layer below. Drag layers in the list to reorder them, or onto a folder to put them in it. **Ctrl+click / Shift+click** picks several layers: drag, move up/down, hide, delete, duplicate, put in a folder, merge (Ctrl+E), change their opacity, blending, locks and labels, flip or move them all at once. Drop or paste images to add them as layers.
- **Vector layers:** Layer → New vector layer keeps every line as a line (its path, brush, colour and opacity), drawn with the pens, pencil, brush, airbrush or the Figure tool's outlines. The Eraser's **Vector** setting picks how it erases there: **Touched area** cuts away only what it passes over, **Up to intersection** removes a line's stretch between the lines it crosses (overshoots vanish in one stroke), **Whole line** removes every line it touches. The Move tool moves the lines and Del clears them. Tools that need pixels (Fill, filters, Transform, Smudge) offer to rasterize the layer first (Layer → Rasterize vector layer); flipping, resizing the canvas or merging into a vector layer rasterizes it. A selection does not cut vector lines. The **Line edit** tool (Y) picks a line to bend by dragging it (softly, over a pull range you set) or to change its width, opacity or colour, or delete it.
- **Layer effects:** Layer → Layer effects… gives a layer a **Border** (an outline of any width and colour round everything on it) and a **Drop shadow** (offset, blur, colour, opacity), shown live while you set them and while you paint. They never change the layer's pixels; Rasterize layer effects (or merging down) makes them pixels.
- **Correction layers:** Layer → New correction layer… adds Brightness/Contrast, Levels, Curves, Hue/Saturation/Lightness, Color balance, Posterize, Threshold, Invert colors or a Gradient map as a layer of its own that changes the colours of everything below it, without changing those layers. Change it again any time (double-click its thumbnail), weaken it with its opacity, paint on its mask to choose where it applies (made from the selection, if there is one), clip it to the layer below, or merge it down to make it permanent.
- **Animation:** View → Animation timeline turns every visible top-level layer or folder into a frame (as Procreate's Animation Assist). The timeline under the canvas shows the frames; click one (or press , and .) to draw on it, add, duplicate or delete frames, play them at 1-60 frames per second, loop or not. Onion skins show the frames before (blue) and after (green) faintly; Settings… picks how many and how strongly, and can keep the bottom layer as a background and the top one as a foreground on every frame. File → Export animation saves an animated GIF or numbered PNG frames.
- **Folders:** new folder, Put in new folder (Ctrl+G), open/close, opacity and blending ("Through" by default, so the layers inside blend as if there were no folder), hide, duplicate, Merge folder (into one layer). The Move tool moves everything in a folder.
- **Layer masks:** add a mask to a layer or folder (with a selection, everything outside it is hidden). Click the mask thumbnail to paint on it: painting hides and erasing shows again, as in Clip Studio Paint. "Painting on mask" shows in the top bar. Turn masks off, apply them or delete them from the Layer menu. View → Show mask area tints what the mask hides in red while you paint on it.
- **Screentone:** Layer → New screentone makes a tone layer (in the selection, if there is one) with a density, dot spacing, angle, shape (dots, lines, squares, diamonds, noise) and dot colour, previewed in the dialog. Paint on a tone layer in gray: darker gives denser dots, white or erasing removes them. Layer → Screentone settings turns any layer into tone (or back) and changes its dots; Rasterize screentone turns the dots into ordinary pixels. Merging a tone layer down keeps its dots.
- **Filters (Filter menu):** Gaussian blur, Sharpen, Mosaic, Motion blur (any angle), Zoom blur and Spin blur (round a centre you click on the canvas or set in %), Add noise (gray or colour grain), Glow (light spilling round the bright parts), Chromatic aberration (red and blue lens fringes), Offset (wrap around, for seamless patterns), Brightness/Contrast, Hue/Saturation/Lightness, Color balance, Curves (drag points on a curve per channel, over a histogram of the layer), Levels, Posterize, Threshold (black and white), Invert colors, **Change color to main color** (recolour line art), **Brightness to opacity** (white becomes clear, for scanned drawings) and **Extract lines** (keeps only lines darker than their surroundings, as black or coloured ink on a clear layer, for scanned sketches). The canvas shows the result live while you drag the sliders; OK keeps it as one undo step, and Ctrl+F repeats the last filter with the same settings. Filters work on the current layer inside the selection, and on a layer mask while you are painting on it (blur a mask to soften its edge).
- **History** (under the tool panel) lists every step you can undo; click one to go back to it, or click a greyed-out step to redo up to it. **Navigator** shows the whole picture with the part in the window outlined: click or drag in it to move the view, scroll over it to zoom.
- **Layer colour labels:** mark layers and folders with a colour in the Layers panel, shown as a dot next to the name.
- **Colour:** HSV square and hue bar, **HSV or RGB sliders** with number boxes, main and sub colour, hex entry, recently used colours, and a **palette** of colours you keep (+ adds the main colour, click to use, right-click to remove).
- **Reference window** (View menu): pictures to look at while you draw, in a floating window you can move and resize. Scroll to zoom, drag to move, click to pick a colour, double-click to fit; + adds pictures (or drop them on it), ‹ › step through them. They are kept in `%LOCALAPPDATA%\KoeStudio\references`, so they are there in every artwork.
- **View:** zoom at the cursor (wheel), rotate (Shift+wheel, 4/5/6), mirror (Shift+M), grayscale view (to check values), fit (Ctrl+0), 100% (Ctrl+1); pixel-sharp when zoomed in.
- **Symmetry ruler:** View → Symmetry settings… mirrors everything you draw left–right, top–bottom or four ways, or repeats it round a centre (radial, or kaleidoscope with mirroring) with 2–32 lines. Pens, brushes, the eraser, Smudge, Liquify and Lasso fill all follow it. Drag its round centre with the Ruler tool; View → Symmetry ruler turns it on and off. Saved with the artwork.
- **Grid:** View → Grid (Ctrl+') shows a grid over the canvas; Grid settings… sets the spacing and divisions and can make strokes started on a grid line follow it and put the corners of selections, figures and crops on the grid.
- **Rulers and perspective:** pixel rulers along the canvas edges (View → Edge rulers). Drag out of them to add horizontal or vertical guides, and drag a guide back to remove it. The Ruler tool (U) adds a 1-, 2- or 3-point perspective ruler and moves its vanishing points and the guides. With snapping on (Ctrl+2, or the magnet in the status bar), each stroke follows the guide it starts on or the perspective line closest to the direction you draw.
- **Undo/redo** for every change, flip layer or canvas, clear or fill a layer.
